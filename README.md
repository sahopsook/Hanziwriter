# Hanzi Writer Web App (แอปฝึกเขียนลำดับขีดอักษรจีน)

เว็บแอปพลิเคชันสำหรับฝึกเขียนตัวอักษรจีน ตรวจสอบลำดับขีด พร้อมแสดงพินอิน ความหมาย ขีด และหมวดนำ (Offline SQLite Database)

## Features
- ค้นหาตัวอักษรจีนได้หลากหลายตัวพร้อมกัน
- แสดงตารางคัดจีน (หมี่จื้อเก๋อ) พร้อมระบบลากนิ้วฝึกเขียน
- ระบบกระพริบนำทางลำดับขีดอัตโนมัติ
- รองรับการใช้งานแบบออฟไลน์ 100% ผ่านฐานข้อมูล SQLite ในเบราว์เซอร์
